### 🚀 QUICK START

```bash
# 1. Clone the repo
git clone https://github.com/ghostscript0x/PULSE.git
cd PULSE

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env
# Edit .env with your:
#   - ZERO_AUTH_API_KEY
#   - ZERO_AUTH_API_BASE_URL
#   - GROQ_API_KEY (for AI insights)
#   - MONGODB_URI

# 4. Start the engine
npm start
```

**PULSE will be running at:** `http://localhost:3000`

### ⚠️ OPERATIONAL RULES

> **These are not suggestions. These are law.**

1. **NO MOCK DATA** — If data doesn't exist, return an explicit error. Never fake it.

2. **NO FABRICATION** — If Zero Authority API is down, the system returns `NETWORK_UNAVAILABLE`. We don't fill gaps with invented numbers.

3. **REAL-TIME COMPUTATION** — Health scores are computed on-the-fly from live metrics, not retrieved from cache.

4. **SNAPSHOT INTEGRITY** — Every snapshot stores the complete raw API response for full auditability.

5. **EXPLICIT ERROR STATES** — The system always communicates what it doesn't know.
